# Algarve Pain Centre Website

React + Vite single-page application for the Algarve Pain Centre marketing site.

## Requirements
- Node.js 18+ recommended

## Scripts
- `npm install` – install dependencies
- `npm run dev` – start local development server
- `npm run build` – production build
- `npm run preview` – preview the production build locally
- `npm test` – run unit tests (Vitest)
- `npm run perf:build` – build + run Lighthouse CI (if available in your environment)
- `npm run backend:dev` – start the Express backend in watch mode
- `npm run backend:start` – start the Express backend in production mode
- `npm run backend:test` – run backend tests

## Backend
- The repository now includes a standalone Node.js / Express backend scaffold in `backend/`.
- See `backend/README.md` for setup, architecture, environment configuration, security notes, and extension guidance.
